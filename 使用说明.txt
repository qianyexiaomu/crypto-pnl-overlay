持仓盈亏悬浮窗 —— 使用说明
================================

一、启动
    双击「OkxPnl.exe」即可（约 90 KB，免安装）。也可双击「启动.vbs」用脚本方式跑。
    重复启动不会叠出两个窗口。

二、填 API Key
    右键 → 填写 / 修改 API Key。
    对话框顶部选交易所（OKX / 币安）。

    OKX：填 API Key + Secret + Passphrase；权限只勾【读取】
    币安：填 API Key + Secret（没有 Passphrase）
    要用平仓再额外勾交易权限，并建议绑定 IP 白名单。

三、交易所与市场
    右键 →「交易所」：OKX（统一账户）/ 币安（U 本位合约）
    右键 →「市场」：合约（永续）/ 现货

    合约：权益、持仓、开仓价、强平价、一键平仓
    现货：每个币的数量、现价、市值（USDT）、24h 涨跌幅；USDT 现金计入权益；
          「平仓」= 市价全部卖出该币种

四、外观
    右键菜单：全透明 / 半透明底板 / 浅色卡片、数字描边、颜色反转（涨绿跌红）等。
    位置：左键拖动，自动记住。

五、快捷键
    Ctrl + Alt + Z   悬浮窗 显示 / 隐藏
    Ctrl + Alt + Q   K 线窗 显示 / 隐藏
    双击             极简单行 / 明细列表

六、看盘与 K 线
    面板内看盘：最多 6 个币对，实时价 + 24h 涨跌幅 + 小 K 线（根数、周期可调）。
    K 线窗：多币种同屏，均线 / 布林带 / 撑压线、开仓与强平价、价格提醒线。

七、安全与网络
    Key 用 Windows DPAPI 加密存本机，换机器需重填。
    直连交易所域名，网络不通时挂系统代理，或在 pnl-config.ini 写 proxy=http://127.0.0.1:7890。

八、卸载
    删掉整个文件夹即可，无注册表、无服务。
