持仓盈亏悬浮窗 —— 使用说明
================================

一、启动
    两种方式，任选一种，效果一样：

    A. 双击「OkxPnl.exe」（推荐）
       单文件，约 90 KB，不用装任何东西（只用 Windows 自带的 .NET Framework 4.x），
       启动不到 1 秒，没有 PowerShell 进程。改完 ps1 后跑一次 build-exe.ps1 重新生成。

    B. 双击「启动.vbs」
       用 PowerShell 跑 OkxPnl.ps1，启动时要现场编译一次 C#（约 1~2 秒）。

    两个版本共用同一份 pnl-config.ini / kline-config.ini，可以随时换着用。
    重复启动不会叠出两个窗口：新实例会把上一个停掉。

二、第一次用要先填 API Key
    右键悬浮条 → 填写 / 修改 API Key。

    API Key 在 OKX 后台创建：账户 → API → 创建 API
    权限只勾【读取】。交易、提现一律不要勾（要用「一键平仓」才需要额外勾【交易】）。
    如果开了 IP 白名单，记得把当前公网 IP 加进去。

    要填三项：
      API Key     —— 后台给的那串
      Secret      —— 只显示一次，务必备份
      Passphrase  —— 你在创建 Key 时自己设的口令（OKX 之后不再显示；忘了只能删掉重建）

    如果用模拟盘，勾上「模拟盘」。

三、安全说明
    · Key 用 Windows DPAPI 加密后存进 pnl-config.ini，只能在本机、本 Windows 账户下解密。
      换机器或重装系统就解不开了，需要重填。
    · 只读权限的 Key 即使泄露也动不了你的钱，这是最重要的一道保险。
    · 程序只与 www.okx.com 通信；看盘行情走 OKX 公有接口，不需要密钥。

四、界面与外观
    默认是【全透明】：没有底板，只有数字浮在桌面上，鼠标点空白处等于点在桌面上。
    右键菜单里可切换：

        「半透明底板」        深色圆角底，任何背景都稳
        「浅色卡片」          浅灰底 + 深色字，像系统时钟，最清楚
        「数字描边」          给数字描一圈深色边（纯透明模式下更好认）
        「文字跟随背景」      透明模式下按背景明暗自动切深/浅字
        「颜色反转」          默认红涨绿跌；打开后涨绿跌红
        「文字浓度」          55% / 72% / 86% / 100%
        「闲置自动变淡」      鼠标移开时变淡，移上去恢复

    位置：左键按住数字拖动，位置会自动记住。

五、快捷键
    Ctrl + Alt + Z   悬浮窗 显示 / 隐藏
    Ctrl + Alt + Q   K 线窗 显示 / 隐藏
    左键拖拽         移动位置
    双击             极简单行 / 明细列表 切换
    右键             菜单

六、两种视图
    极简单行：  ● 12,345.7   +424.5
                左边小圆点 = 状态灯：灰=读取中  绿=正常  红=失败  黄=没配 Key

    明细列表（双击切换）：
        权益 12,345.67            +424.50
        BTC 多    +12.6%    +600.5
        ETH 空     -2.9%    -176.0

    盈利红、亏损绿（可在菜单里反过来）。最多显示 6 条，按盈亏绝对值排序。

七、数据口径
    权益     = 交易账户总权益，USD 计价（totalEq）
    浮盈浮亏 = 当前所有持仓未实现盈亏之和（upl）
    明细     = 每个持仓的方向、涨跌幅、未实现盈亏
               没有持仓时只显示权益，下面写一行「无持仓」——空仓时没有可画的数据，这是正常的。

八、实时看盘（面板内）
    明细模式下，权益下面每个看盘币对占一行：
        权益 68.92                       +0.2
        ZEC   ▂▃▅    981.30   -14.6%
        ETH   ▂▃▅  2,056.10    -2.7%

    三列：币种 | 中间是小 K 线 + 实时价 | 右边是 24 小时涨跌幅。
    右键菜单：
        「实时看盘（面板内一行）」  整块开 / 关
        「看盘币对」                多选，点一下勾上、再点一下取消
        「添加看盘币对…」          一次填多个，逗号分隔，最多 6 个
        「看盘显示价格」            关掉只留涨跌幅
        「小K线根数」               3 / 5 / 8 / 12 / 16 根
        「小K线周期」               默认跟随看盘周期，也可单独固定
        「看盘周期」                1m / 5m / 15m / 1H / 4H / 1D

    24 小时涨跌幅取 OKX 公有行情接口的 open24h 与最新价，和周期无关。

九、K 线窗（独立窗口，Ctrl+Alt+Q）
    可以同时看多个币种，每个币种一行：名字、涨跌幅、最新价，下面一整条 K 线。
    右键菜单：
        「添加币对」/「移除当前币对」   最多 8 个
        「K线根数」                     30/48/80/120/200/300，或自定义 20~300
        「周期」                        1m / 5m / 15m / 1H / 4H / 1D
        「刷新频率」                    1 / 2 / 3 / 5 秒
        「辅助线（可自由勾选）」        均线 MA5 / MA10 / MA20 各自独立、
                                        布林带 BOLL(20,2)、撑压线（区间高低）
        「价格提醒」                    给当前币种加价位线，穿线响一声（60 秒内只响一次），
                                        可清除单个/全部
        「深色底板」                    关掉就是纯透明

    图上还会自动画两条价位线（有持仓时）：
        「开」   —— 开仓均价
        「强平」 —— 强平价（红色加粗）

十、一键平仓
    右键 →「一键平仓」，按持仓逐条列出，点某一条会弹确认框
    （显示币对/方向/数量/开仓均价/当前浮盈），点「是」才真正下单。

    用的是 OKX 的市价全平接口（/api/v5/trade/close-position），逐笔独立。
    ★ OKX 需要 Key 勾【交易】权限；币安需要勾【允许合约交易】。只读 Key 会被拒绝并弹错误码。
    ⚠ 一旦开了交易权限，这把 Key 就能下单。建议绑定 IP 白名单，并妥善保管。

十一、连不上怎么办
    OKX 的域名在国内多数网络会被污染（解析到 169.254.0.2），必须走代理。
    · 开了 Clash / v2ray 的「系统代理」，本工具默认就会跟随，不用配。
    · 用的是 TUN 模式，一般也能直连。
    · 都不行就手动指定：右键 → 查看连接状态，先看错误信息；
      然后在 pnl-config.ini 里加一行
          proxy=http://127.0.0.1:7890
      （端口换成你自己的），重开程序。

十二、常见报错
    50101 / Invalid OK-ACCESS-KEY     Key 填错或已删除
    50113 / Invalid Sign              本机时间不准，同步一下系统时间
    50105 / Passphrase 错误            口令填错
    50110 / Invalid IP                 IP 不在白名单
    51001 / Instrument ID does not exist   交易对写错

十三、打包成 exe / 二次开发
    build-exe.ps1 会把 OkxPnl.ps1 里内嵌的 C# 抽到 src/OkxPnl.Core.cs，
    再和 src/Program.cs 一起用 Windows 自带的 csc.exe 编成 OkxPnl.exe（.NET Framework 4.x）。
    改代码只改 OkxPnl.ps1，然后跑一次：
        powershell -NoProfile -ExecutionPolicy Bypass -File .\build-exe.ps1

十四、清理
    程序本身无服务、无注册表写入。删掉整个文件夹即可（配置和 Key 都在 pnl-config.ini 里）。
